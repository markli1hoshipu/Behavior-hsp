# Plan: Interactive Replay-to-Failure + Controller Takeover + Continue Recording

## Goal
Create a system that:
1. **Interactively replays** HDF5 data while user watches the simulation
2. User presses a key when they see a failure to **trigger takeover mode**
3. Another controller (policy or joylo) takes over from that exact point
4. Records the **complete trajectory** (pre-failure from HDF5 + post-takeover new data) to a new HDF5 file

---

## Parquet vs HDF5 Analysis

**Can parquet+video achieve the same result?** **NO**

| Capability | HDF5 | Parquet+Video |
|------------|------|---------------|
| Serialized sim state | YES (`og.sim.dump_state()`) | NO |
| Restore to arbitrary step | YES (`og.sim.load_state()`) | NO |
| Object positions/physics | YES | NO |
| Scene configuration | YES | NO |

**Parquet stores only:**
- Proprioception (joint positions/velocities)
- Camera relative poses
- Actions
- Task metadata

**Missing for takeover:** Full object states, scene configuration, physics state

**Conclusion:** Must use HDF5 for replay-to-takeover. Parquet is only suitable for final output after successful recording.

---

## Key Insights

### HDF5 Structure
```
demo_0/
  state[T, max_state_size]     # Serialized simulator states
  state_size[T]                 # Actual size of each state
  action[T-1, action_dim]       # Actions (T-1 entries)
  transitions                   # Object/system add/remove events
  init_metadata/                # Object attributes at start
```

### Direct State Loading
```python
og.sim.load_state(state[N, :int(state_size[N])], serialized=True)
```
Restores simulator to exact state at step N - no need to replay physics.

### Joylo Hardware Sync
```python
# In gello_agent.py
agent.set_reset_qpos(target_qpos)  # Set target
agent.reset()                       # Move hardware to target
```

### Phase 3: Implement Interactive Replay Loop

**Key implementation in InteractiveReplayTakeoverWrapper:**

```python
def interactive_replay(self, episode_id: int, n_render_iterations: int = 3) -> int:
    """Returns takeover step, or -1 if replay completed."""
    import sys
    import select

    traj_grp = self.input_hdf5["data"][f"demo_{episode_id}"]
    transitions = json.loads(traj_grp.attrs["transitions"])
    state = th.from_numpy(traj_grp["state"][:])
    state_size = th.from_numpy(traj_grp["state_size"][:])
    action = th.from_numpy(traj_grp["action"][:])
    init_metadata = {k: th.from_numpy(v[:]) for k, v in traj_grp["init_metadata"].items()}

    # Restore scene
    scene_file = json.loads(self.input_hdf5["data"].attrs["scene_file"])
    self.scene.restore(scene_file, update_initial_file=True)

    # Restore init_metadata
    with og.sim.stopped():
        for i, obj in enumerate(self.scene.objects):
            for attr, vals in init_metadata.items():
                setattr(obj, attr, vals[i].item() if vals[i].ndim == 0 else vals[i])

    # Load initial state
    og.sim.load_state(state[0, :int(state_size[0])], serialized=True)
    self.env.step(action[0], n_render_iterations=n_render_iterations)  # Render

    print("Press 't' to trigger takeover, 'q' to quit...")

    for i in range(len(action)):
        # Check for keyboard input (non-blocking)
        if self._check_takeover_key():
            print(f"\nTakeover triggered at step {i}")
            return i

        # Apply transitions at this step
        if str(i) in transitions:
            self._apply_transitions(transitions[str(i)])
            self.current_transitions[i] = transitions[str(i)]

        # Load state and step (for rendering)
        og.sim.load_state(state[i+1, :int(state_size[i+1])], serialized=True)
        self.env.step(action[i], n_render_iterations=n_render_iterations)

        if i % 100 == 0:
            print(f"\rStep {i}/{len(action)}...", end="", flush=True)

    print("\nReplay completed")
    return -1

def _check_takeover_key(self) -> bool:
    """Non-blocking check for takeover key press."""
    import sys
    import select
    import termios
    import tty

    # Check if input available
    if select.select([sys.stdin], [], [], 0.0)[0]:
        key = sys.stdin.read(1)
        return key.lower() == 't'
    return False
```

### Phase 4: Prepare Takeover (Copy Pre-Takeover Data)

```python
def prepare_takeover(self, episode_id: int, takeover_step: int):
    """Copy replayed data to current trajectory for seamless recording."""
    traj_grp = self.input_hdf5["data"][f"demo_{episode_id}"]
    state = th.from_numpy(traj_grp["state"][:])
    state_size = th.from_numpy(traj_grp["state_size"][:])
    action = th.from_numpy(traj_grp["action"][:])

    # Clear any existing trajectory data
    self.current_traj_history = []
    self.max_state_size = 0

    # Copy initial state (no action)
    self.current_traj_history.append({
        "state": state[0, :int(state_size[0])],
        "state_size": int(state_size[0]),
    })
    self.max_state_size = int(state_size[0])

    # Copy steps 1 to takeover_step (with actions)
    for i in range(takeover_step):
        self.current_traj_history.append({
            "action": action[i],
            "state": state[i+1, :int(state_size[i+1])],
            "state_size": int(state_size[i+1]),
            "reward": 0.0,
            "terminated": False,
            "truncated": False,
        })
        self.max_state_size = max(self.max_state_size, int(state_size[i+1]))

    self.takeover_step = takeover_step
    self.in_takeover_mode = True
    print(f"Prepared takeover: copied {takeover_step + 1} states, {takeover_step} actions")
```
